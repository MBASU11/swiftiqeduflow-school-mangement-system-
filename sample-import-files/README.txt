Sample files for Import & Export
=================================
*-template.xlsx            Blank templates with one example row and an Instructions sheet.
example-messy-learners-list.xlsx
                           A typical school list (title rows, own column names, dates written day/month/year,
                           "Grade 1 A" meaning class + stream). Import it under Students to see the matching screen.

Marks: use Import & Export -> Marks -> "Download class marks sheet". It comes pre-filled with the class list and
that grade's subjects, ready for marks to be typed in.
